QuackMuzik 🦆🎵

Discord music bot được xây dựng với Lavalink, hỗ trợ nhiều nền tảng nhạc (YouTube, Spotify, Apple Music, SoundCloud, Deezer và nhiều hơn nữa) với khả năng text-to-speech.

✨ Tính năng nổi bật

🎵 Hỗ trợ đa nền tảng

  • YouTube / YouTube Music
  • Spotify
  • Apple Music
  • SoundCloud
  • Deezer, Yandex Music
  • Bandcamp, Twitch, Vimeo
  • HTTP streams

🎤 Text-to-Speech

  • Tích hợp FloweryTTS
  • Cấu hình giọng nói, tốc độ
  • Hỗ trợ dịch thuật

🎛️ Điều khiển nhạc

  • Quản lý queue
  • Play, skip, jump, seek
  • Hiển thị now playing với nút tương tác
  • Quản lý playlist
  • Theo dõi lịch sử phát
  • Vote skip với DJ role bypass

🌐 Đa ngôn ngữ

  • Hỗ trợ tiếng Việt & tiếng Anh
  • Cấu hình ngôn ngữ theo server
  • Thông báo được dịch

⚙️ Tùy chỉnh

  • Prefix tùy chỉnh
  • Cấu hình ngôn ngữ
  • Phân quyền lệnh
  • Hệ thống cooldown
  • DJ role configuration
  • 24/7 Mode (bot ở lại voice channel)
  • Track announcement toggle
  • DJ audio filters (Bassboost, Nightcore, Lo-fi, Vaporwave, 8D Audio)

📊 Logging & Monitoring

  • Structured JSON logs
  • Theo dõi lệnh
  • Lavalink event logging
  • Debug mode

🏆 Leaderboards & Gamification

  • Top DJs (most requests)
  • Top Listeners (most listening time)
  • Top Hits (most played tracks)
  • Personal stats và rankings
  • Period-based rankings (week, month, all time)
  • Auto-tracking user activity

🚀 Bắt đầu nhanh

QuackMuzik được thiết kế để dễ dàng triển khai và sử dụng:

  • Docker Compose: Chạy bot, Lavalink và database chỉ với một lệnh
  • Kubernetes: Helm charts sẵn có cho production deployment
  • CI/CD: GitHub Actions tự động build và deploy
